# 커리어 메뉴 품질 감사와 개선 계획

## 범위

- 대상 메뉴: `CAREER_HANDBOOKS`
- 대상 문서 수: 17개
- 원본: `public/handbook/career-*-handbook.html`
- 생성 산출물: `src/handbook/documents/career-*.ts`, `src/handbook/searchIndex.mjs`
- 카탈로그: `src/handbook/catalog.mjs`

## 진단 요약

| 문서군 | 상태 | 발견 내용 |
| --- | --- | --- |
| 전략/면접 번들 | 개선 필요 | `학습 로드맵`, `CAREER READINESS GATE`, `EVIDENCE PACKET`는 역할이 있으나 PART 구분 섹션 일부가 제목만 있음 |
| 공통 증거 기준 | 중복 심각 | `증거·과장 방지 기준`이 9개 문서에 동일 본문으로 반복됨 |
| LinkedIn 이력서 | 보강 필요 | 실제 프로필 문안은 있으나 타깃별 변형, bullet 검수, 공개 범위 기준이 부족함 |
| 시장 요구 분석 | 보강 필요 | 표본 분석의 품질은 좋으나 갱신 절차와 stale 방지 기준이 약함 |
| 산출물/이직 실행/노선 문서 | 대체로 양호 | 실행 순서와 산출물 중심 구조는 유지 가능 |
| 메뉴 순서 | 개선 필요 | `01R-*`가 많아 진단, 노선, 시장, 산출물, 실행 단계가 한눈에 보이지 않음 |

## 개선 계획

1. 중복 제거
   - 공통 `증거·과장 방지 기준`은 전략/개인 이력 문서에 기준 역할로 남긴다.
   - 나머지 면접/포트폴리오 문서는 도메인별 과장 방지 기준으로 교체한다.

2. 부실 보강
   - 제목만 있는 PART 섹션에 각 파트의 검증 초점, 먼저 볼 질문, 준비 산출물을 추가한다.
   - LinkedIn 이력서에 타깃별 헤드라인, 경력 bullet 규칙, 공개 범위 검수 섹션을 추가한다.
   - 시장 요구 분석에 갱신 프로토콜과 stale 신호를 추가한다.

3. 메뉴 재정렬
   - 커리어 메뉴를 `전략 -> 원장 -> 이력서 -> 성장 -> 노선 -> 시장 -> 산출물 -> 이직 실행 -> 면접 대비` 순서로 정렬한다.

4. 회귀 방지
   - 커리어 문서의 완전 동일 `증거·과장 방지 기준` 반복을 테스트로 막는다.
   - 제목만 있는 PART 섹션이 다시 생기지 않도록 최소 본문 길이를 검사한다.
   - LinkedIn/시장 분석 보강 섹션의 존재를 검사한다.
